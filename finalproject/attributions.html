Project Resource Attributions

The operational layout properties for EduPulse were constructed completely from scratch by the student. The following sources were used for inspiration and baseline guidelines:

  • Inspirational Text: Uchtdorf, Dieter F. "Happiness, Your Heritage" text block provided via course task parameters.
  • Mock Student Data Matrix: Formulated manually in local JSON files to cleanly replicate nursery, primary, and secondary student tracking models.
  • Architecture Inspiration: Native accessible standard dialog structural specifications referenced directly via MDN Web Docs.
